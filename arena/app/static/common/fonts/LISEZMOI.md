# Police

L'interface est dessinée pour **SF Pro Display** (Regular, Medium, Bold). Sa licence Apple interdit de la
redistribuer : elle n'est donc pas dans ce dépôt. Sans elle, les pages utilisent la police système (Segoe UI sous
Windows, San Francisco sous macOS), ce qui fonctionne très bien.

Si tu as la police (elle est fournie gratuitement aux développeurs Apple), dépose ces trois fichiers ici puis recharge
la page :

- `SFPRODISPLAYREGULAR.OTF`
- `SFPRODISPLAYMEDIUM.OTF`
- `SFPRODISPLAYBOLD.OTF`
